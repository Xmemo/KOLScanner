# CDE Generic Drug BE Public Data Index

This repository provides a structured dataset derived from publicly available NMPA/CDE information on generic drug bioequivalence (BE) evaluations.

## Scope
- Only public regulatory documents
- No medical advice or drug recommendation
- Pure data structuring layer

## Data Model
Each record represents:
Generic name + dosage form + strength + manufacturer + acceptance number + BE results

## Disclaimer
This project is for research and data transparency only.
It does NOT provide medical advice, diagnosis, or treatment guidance.
